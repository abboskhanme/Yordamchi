Fetch a file for the owner from a link (`url`): the file itself when the link is a file, or the main image of a page when it is a page. It is sent to him, up to 50 MB; with `as_file` true it goes as a file even when it is an image. Use it only when he asks to get or send him an image or file from a link. The result only says the download has started (`status`, `site`); the file, or the reason it could not come, reaches him after your answer, so say in one short line that it is coming.
